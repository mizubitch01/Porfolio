I'm an Information Technology student who treats every subject as a chance to build something real.

My program covers the full stack of IT — programming fundamentals, data structures, database management, systems administration, and network configuration. Instead of memorising for exams and moving on, I turn each topic into a small project: a working app, a configured topology, a script that automates the boring part.

On the development side, I build responsive web interfaces with HTML, CSS, JavaScript and React, and back them with Python or Node APIs. On the networking side, I've worked through multi-area OSPF routing, VLAN segmentation, subnetting, and Cisco IOS configuration — the kind of hands-on lab work that makes the theory finally click.

What I enjoy most is the overlap: writing a Python script that generates router configs, or building a dashboard that visualises network health. That's where my two interests stop competing and start compounding.

Right now I'm looking for an internship or junior role where I can contribute to real systems, learn from people further along than me, and keep shipping things that work.
